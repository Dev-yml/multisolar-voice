# Security review — Multi Solar Voice (Console + Voice Agent server)

Checked against 20 common web-app risks. ✅ = protected, 🔧 = fixed in this review, ⚠️ = open / action needed.

| # | Risk | Status | How |
|---|---|---|---|
| 1 | SQL injection | ✅ | All database access through Prisma with parameters; no raw SQL in the app. The only SQL file (`prisma/rls.sql`) has no user input. |
| 2 | Cross-site scripting | ✅ 🔧 | React escapes all output; no `dangerouslySetInnerHTML`. **Added** a strict Content-Security-Policy (scripts only from this site, no plugins, no framing). Recording links must be `https://`. |
| 3 | CSRF | ✅ 🔧 | Session cookie is `SameSite=Strict` + HttpOnly; Next.js server actions check the Origin. **Added** an Origin check on every non-GET `/api/` request. |
| 4 | Insecure file uploads | ✅ | Knowledge: PDF/DOCX/TXT/MD/CSV/JSON only, max 10 MB, parsed in memory, never stored or served back. CSV import max 2 MB / 5000 rows. Managers only. |
| 5 | IDOR / object-level auth | 🔧 | Every page and action checks the signed-in user and role on the server. **Fixed:** the test-call API accepted any call id — a staff user could inject text into, or end, a real phone call. Now it only works on browser test calls. |
| 6 | Rate limiting | 🔧 | **Fixed:** the login limit was in server memory (useless on Vercel's many instances). Now stored in the database: 5 failures per account or 20 per IP in 15 minutes, plus a delay on every failure. Test-call API limited per user. |
| 7 | JWT secrets | ✅ | HS256 pinned (no `alg:none`), issuer checked, 8-hour expiry, `AUTH_SECRET` must be 32+ random characters (generated by setup). Role and "active" re-checked in the database on every request. |
| 8 | Exposed API secrets | ✅ | No `NEXT_PUBLIC_` variables; keys only in server `.env` / host settings; `.env*` git-ignored and never in zips; server code marked `server-only`. |
| 9 | Password hashing | ✅ 🔧 | bcrypt cost 12, constant-time check for unknown emails. **Added** a 72-byte maximum (bcrypt ignores the rest). |
| 10 | Multi-factor authentication | ✅ 🔧 | **Built:** required for every user. Authenticator-app codes (TOTP, RFC 6238), secret AES-256-GCM encrypted, codes cannot be reused, 5 wrong codes = 15-min lock, 8 one-time recovery codes (hashed), Super Admin can reset, all sessions revoked on password change / reset / deactivation. Emergency: `npm run mfa:reset -- email`. |
| 11 | CORS | ✅ | No CORS headers anywhere → browsers only allow same-site calls. Voice server needs a secret key on every endpoint. |
| 12 | Tokens in localStorage | ✅ | Session only in an HttpOnly cookie; nothing in localStorage/sessionStorage. |
| 13 | Client-side-only permissions | ✅ | The menu hides links, but every page/action/API re-checks the role on the server. |
| 14 | Row-level security (Supabase) | ✅ 🔧 | RLS on all tables and the public API roles revoked. **Added** `prisma/rls.sql`, run by `npm run setup` after every migration, so future tables are locked too. |
| 15 | Webhook signatures | ⚠️ 🔧 | Smartflo does not sign webhooks. Protection = a long secret key compared in constant time. **Added** support for sending it as a header (`x-msv-key`) instead of in the URL — use that in the Smartflo webhook settings. |
| 16 | SSRF | ✅ | The servers only call fixed addresses from settings (Sarvam, Smartflo, the voice server). No user-supplied URL is ever fetched. |
| 17 | Source maps | ✅ | Next.js production builds do not publish browser source maps (not enabled in `next.config.ts`). |
| 18 | Default credentials | ✅ 🔧 | No built-in passwords: the first admin password is random (setup). **Added** a "My account" page to change it — do this after the first sign-in, then delete `SEED_ADMIN_PASSWORD` from `.env`. |
| 19 | Sensitive data in logs | 🔧 | **Fixed:** the voice server logged what callers said and lead names. Now logs only ids, lengths and the last 4 digits of numbers (`LOG_TRANSCRIPTS=1` only for debugging). |
| 20 | Vulnerable dependencies | ⚠️ | `npm audit`: remaining findings are in tools that never handle user input at run time — Prisma CLI (`deepmerge-ts`), eslint (`braces`), Word reader's command-line part (`sprintf-js`). Fixed `postcss`. Do **not** run `npm audit fix --force` (it downgrades Next/Prisma). Re-check monthly. |
